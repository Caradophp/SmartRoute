## 🔧 Pré-requisitos

Antes de começar, certifique-se de ter as seguintes ferramentas instaladas:

| Ferramenta | Requisito | Finalidade |
|---|---|---|
| Git | Versão estável | Clonagem e gerenciamento do repositório |
| Node.js | Versão LTS | Execução do frontend |
| npm ou Yarn | Versão compatível com o projeto | Gerenciamento de dependências do frontend |
| Java | Versão 21 ou superior | Execução do backend |
| Maven | Versão compatível com o projeto | Compilação e gerenciamento de dependências do backend |
| Docker | Opcional | Execução de serviços em contêineres |

> **💡 Observação:** Instale apenas as ferramentas necessárias para o stack que pretende executar. Consulte a documentação específica de cada módulo para verificar requisitos adicionais.
